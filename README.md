- Semantic HTML
- Custom CSS
- Vanilla JavaScript
- GSAP + ScrollTrigger
- GitHub Pages
- Jekyll sitemap plugin

## Local preview

Open `index.html` in a browser or serve the repository root with a local static web server.

## Deployment

The `master` branch is published through GitHub Pages at [albertodesidera.eu](https://albertodesidera.eu/).

The custom domain is configured through the repository's `CNAME` file and DNS records managed at Spaceship.
